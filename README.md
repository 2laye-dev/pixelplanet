# پیکسل پلنت

وب‌سایت تک‌صفحه‌ای فارسی برای معرفی خدمات طراحی وب، UI/UX و سئو، همراه با پنل مدیریت واقعی.

## اجرای محلی

Node.js 22 یا 24 لازم است.

```sh
npm ci
node scripts/setup-local.cjs
npm run dev
```

سایت: http://localhost:3000 — پنل: http://localhost:3000/admin

اسکریپت راه‌اندازی یک رمز تصادفی می‌سازد و آن را فقط در `LOCAL-ACCESS.txt` ذخیره می‌کند. این فایل و `.env.local` داخل بسته انتشار قرار نمی‌گیرند. فایل تنظیمات موجود بازنویسی نمی‌شود.

## امکانات

- صحنه WebGL با Three.js، بازتاب فلزی، حرکت با اسکرول و اشاره‌گر؛ نمایش جایگزین بدون WebGL و احترام به کاهش حرکت سیستم.
- طراحی واکنش‌گرا و RTL با فونت‌های محلی استعداد و Manrope.
- نمونه‌کارهای واقعی لبخندیاب، شایگان سافت و مژیتو؛ تصویر صفحه از سایت‌های معرفی‌شده دریافت شده است.
- افزودن لینک، عنوان و توضیح اختیاری، انتخاب چند دسته، تصویر، ترتیب، انتشار و پنهان‌سازی یا حذف.
- بارگذاری تصویر PNG/JPG/WebP تا ۵ مگابایت.
- تماس، واتساپ، تلگرام و فرم درخواست همکاری؛ صندوق درخواست‌ها در پنل.
- صدای محیط اختیاری، خاموش به‌صورت پیش‌فرض.

## داده و امنیت

داده‌ها در `DATA_DIR/content.json` و تصاویر در `DATA_DIR/uploads/` ذخیره می‌شوند. مسیر پیش‌فرض `data/` در ریشه برنامه است. ذخیره اتمیک با قفل بین پردازه‌ها برای اجرای چند worker روی یک میزبان انجام می‌شود. نیاز به MySQL ندارد. برای چند سرور مستقل یا حجم بالای پیام، لایه ذخیره‌سازی باید به پایگاه داده مشترک منتقل شود.

رمز با scrypt هش می‌شود. نشست امضاشده، HttpOnly و SameSite=Strict است و ۸ ساعت اعتبار دارد. تغییر رمز یا کلید نشست، نشست‌های قبلی را باطل می‌کند. درخواست‌های نوشتن به کنترل مبدأ و احراز هویت مجهز هستند. محدودیت ورود ۱۲ بار در ۱۵ دقیقه برای کل پنل است؛ پیام‌ها برای هر راه تماس ۳ بار در ساعت و مجموعاً ۱۰۰ بار در ساعت محدود هستند. ورود به تنظیم ADMIN_PASSWORD_HASH و SESSION_SECRET وابسته است و رمز پیش‌فرض تولیدی ندارد.

پروژه جدید با تنها لینک و دسته قابل ذخیره است؛ در نبود عنوان از دامنه و در نبود تصویر از قاب تایپوگرافیک استفاده می‌شود. سایت به‌صورت خودکار URL واردشده را واکشی نمی‌کند. هیچ آمار سئو یا انتساب UI/UX اختراع نشده؛ دسته‌ها را براساس پروژه واقعی در پنل انتخاب کنید.

## بررسی و بسته‌بندی

```sh
npm test
npm run build
node scripts/smoke.cjs
npm run package
```

خروجی: `release/pixelplanet-cpanel.zip`. سورس و بیلد تولیدی در بسته هستند؛ node_modules، رمزها و داده‌های واقعی بسته‌بندی نمی‌شوند. راهنمای کامل در `DEPLOY-CPANEL.md` است.

## مرجع و مجوزها

مرجع بصری کاربر: https://www.sybiosme.com/en . هندسه سه‌بعدی و کد پروژه از نو نوشته شده‌اند؛ بازسازی برداشت بصری است و کپی پیکسلی تمام حالت‌های مرجع تأیید نشده است. تصاویر نمونه‌کارها متعلق به سایت‌های معرفی‌شده کاربرند. مجوز فونت‌ها در `public/fonts/` قرار دارد.
